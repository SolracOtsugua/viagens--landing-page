# 🌍 TripMe - Landing Page de Viagens

Bem-vindo ao **TripMe**! Este é um projeto de uma Landing Page moderna e responsiva focada em roteiros de viagens exclusivos pelos vilarejos misteriosos e encantadores da Europa.

## 🚀 Sobre o Projeto

O objetivo deste projeto foi criar uma página de destino (Landing Page) utilizando boas práticas de HTML semântico e CSS moderno, focando na experiência do usuário (UX).

### ✨ Funcionalidades
* **Navegação Suave (Smooth Scroll):** Ao clicar nos links do menu ou em "Voltar ao topo", a página desliza suavemente até o destino.
* **Animações Interativas:** Os cards de conteúdo possuem efeitos de levitação e sombra ao passar o mouse (`hover`).
* **Layout Responsivo:** Estrutura organizada para facilitar a leitura.
* **Menu Fixo:** A barra de navegação permanece no topo durante a rolagem.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização, animações de transição e efeitos visuais.
* **Git & GitHub**: Controle de versão e hospedagem do código.

## 📸 Prévia do Visual

O projeto conta com:
1.  **Banner Hero**: Com imagem de fundo e chamada para ação (CTA).
2.  **Seções de Conteúdo**: Organizadas em cartões (Cards) com informações sobre roteiros, contatos e conselhos.
3.  **Rodapé**: Informações de direitos autorais.
